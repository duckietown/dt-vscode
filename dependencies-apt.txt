# Runtime libraries that OpenCV's native module (cv2) dynamically links against.
# On arm64 the installed opencv-python-headless wheel (from piwheels) links the
# system ffmpeg/gstreamer libs instead of bundling them, so `import cv2` fails
# with "libavcodec.so.60: cannot open shared object file" on arm64 hosts (e.g.
# Apple Silicon / OrbStack). On amd64 the PyPI wheel bundles these, so the
# packages are a harmless no-op there. Installed here so every LX editor image
# (all build FROM dt-vscode) inherits them without per-recipe duplication.
libavcodec60
libavformat60
libavutil58
libswscale7
libgstreamer1.0-0
libgstreamer-plugins-base1.0-0
